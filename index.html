Salt for VCF Tooling

Welcome to the Salt for VCF Tooling site. Here, we collect and document open source Salt content for managing VMware Cloud Foundation, including the individual VMware components.

With the introduction of the VMware Salt for VCF Component APIs in VMware Cloud Foundation 9.1.1, there's a lot more you can do programmatically with Salt with the VCF Components as the endpoint targets. The Salt capabilities are bounded by what VMware allows since they are proprietary appliances so it's not as open as an endpoint which you have full control over. VMware has committed to increasing the capabilties over time and we will document those new capabilities as they are released. We will also explore open source Salt functionality that will be built on those Salt for VCF capabilities.

Here are some Salt tools for VCF available today:

1. The Salt Extensions for VCF

The Salt Extensions for VMware have been around a long time but in 2026, the open source developers fully updated the extensions to work with VCF 9.1. The link will take you directly to the Salt Extensions for VCF github location. It assumes prior knowledge of Salt, including how to install extensions, how to use it with an existing implementation, and access to VMware appliance credentials. If you are new to using Salt and want to experiment with the open source Salt functionality with VMware appliances, try The Salt Appliance.

2. The Salt Appliance for VCF

This is an OVA based Photon appliance you can deploy in a vSphere environment that has the latest Salt Master and Minion (as of this writing, 3008.5) installed and working. In addition, the Salt Extensions for VCF are already installed on this appliance. The working instructions on how to deploy and use the appliance are here.

3. The Salt for VCF State and Jinja File Generator - VCF 9.1.1

This static webform follows the format and schema outlined for the state and jinja files needed to manage VCF component configuration settings with Salt for VCF API. The schema and format is documented in The Anatomy of a Salt for VCF State File and The Anatomy of a Salt for VCF Jinja File from the Broadcom Developer API reference. The  Salt for VCF API Reference and the Salt for VCF State and Jinja File Generator - VCF 9.1.1 are authored by the same person.

This webform can also be downloaded and used offline since the content of the webform is static.

4. Hybrid Salt Model

This is a placeholder for the coming functionality planned for VCF where you can develop your own Salt functionality using the existing VCF Component APIs, host it on your own device, connect it up to a VCF instance, and trigger the custom functionality.
